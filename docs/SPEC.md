# WISEMAN — RESEARCH SESSION 001 仕様

対象は [PR #6](https://github.com/mila411/wiseman/pull/6) の本編実装と、ローカルの実測済み素材。基準コミットは `4e8281002121f3645408735042db851b6e03d0c5`。この文書での時刻は、特記がない限り本編開始からの経過時間。

## 表現と画面

- WISEMAN は架空の匿名音声会議。映像には会議画面だけを使用する。人物映像、サイドバー、チャット履歴、入力欄は設けない。
- 本編の画面は黒に近い青の背景。左上に鍵アイコン、`PRIVATE SESSION`、`WISEMAN`、`Encrypted voice conference · 5 participants`。右上に接続状態と UTC を表示する。
- 参加者は ORACLE、GHOST、ZERO、SPECTER、ROOT の順に縦に並ぶ。各行に匿名アバター、名前、状態を表示する。発話中は行を強調し、緑の `Speaking` と波形を表示する。非発話時は接続状態を表示する。
- 字幕は発話者の行に表示する。長文は行の範囲内でスクロールできる。
- 下部はマイク、赤い切断、設定の丸ボタンと Session ID `7F92A1`。マイクと設定は無効。Web アプリには会議画面の下に再生・一時停止、先頭から再生する Restart、シーク、素材の取り込みがある。
- 上部の時計は端末の現在 UTC を表示する。

## キャラクターと声

現行の生成処理は Foundry の `gpt-4o-mini-tts` に、自然な米国英語で台詞だけを読むよう指示する。下表はコード上の声と演技指示。

| 話者 | 脚本上の役割 | 声と演技指示 | 本編キュー数 |
| --- | --- | --- | ---: |
| ORACLE | 司会・調査の指示 | `alloy`。落ち着いて、間を取り、指揮を執る口調 | 27 |
| GHOST | Bluetooth と CoreUtils の公表情報 | `echo`。淡々と簡潔に、安定した低めの声 | 19 |
| ZERO | ARM64、PAC、オブジェクト寿命 | `ash`。分析的で正確、考えながら話す口調 | 15 |
| SPECTER | WebKit 側の調査手法との比較 | `coral`。落ち着いた会話調、明瞭な発音 | 15 |
| ROOT | 仮説と観測事実を区別し、所見をまとめる | 全編無音。字幕、Speaking、波形は表示する | 26 |

## 台本と実測タイミング

正式脚本は [SCRIPT_SESSION_001.md](SCRIPT_SESSION_001.md)。CVE の確認結果と未確認事項は [SESSION_001_FACT_CHECK.md](SESSION_001_FACT_CHECK.md)。発話の正確な開始・終了は、実測済み `production/session-001/cues.json` と対応する `scenario.json` を参照する。以下は各 ACT の最初と最後の字幕キューの時刻で、幕間や終端の無発話区間を含まない。

| ACT | 最初の字幕開始 | 最後の字幕終了 |
| --- | ---: | ---: |
| I — Reassembly | 00:05.200 | 01:04.133 |
| II — Bluetooth and iOS | 01:05.000 | 02:33.415 |
| III — Memory Corruption | 02:33.765 | 04:04.480 |
| IV — The Slip | 04:04.830 | 05:07.110 |
| V — Attack Surface and Evidence | 05:09.830 | 06:53.740 |
| VI — Assignment | 06:54.090 | 08:03.745 |
| VII — Termination | 08:04.095 | 08:20.848 |

- 本編は **8分34.095秒**。102キューのうち76本に音声があり、発話音声の合計は366.950秒。台本の 7:45 は計画尺。実装では音声が枠を超えた場合に後続の ACT を移動し、台詞を収める。
- ROOT の `S001-U046` は **04:17.935–04:20.185**。ロシア語原文「Нет, подожди... чёрт.」とカタカナ「ニェート、パダジー……チョルト。」を表示する。直前の英語字幕終了から0.700秒、次の英語字幕開始まで1.000秒。特別な効果音や警告を出さず、他の参加者はロシア語に反応しない。ほかの台詞のロシア語訳は原文にない。

## 動きと音声同期

- 冒頭0.900秒は暗転。最初の接続で短い電子音が鳴り、5人が表示順に0.650秒間隔で接続する。
- 発話区間は開始を含み終了を含まない。話者の表示、字幕、音声を同じタイムラインから計算する。音声がある行の波形はデコードしたサンプルのピークを使い、ROOT と音声未読込の発話は時刻から計算した波形を使う。波形は47本のバー。
- 終盤は SPECTER、ZERO、GHOST、ROOT、ORACLE の順に切断する。終了後に `SECURE SESSION TERMINATED` と `END OF TRANSMISSION` を表示する。
